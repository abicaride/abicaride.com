## Context

An exercise from the UX Writing postgraduate course at SHIFTA by Elisava, exploring how a familiar dead end can still feel specific to a product.

## Approach

I created 404 concepts for Fridays for Future, Patagonia, Holaluz and Xataka. Each message gives the user a useful next step while changing vocabulary, rhythm and humour to fit the organisation behind it.

## Learning

Even a tiny piece of interface copy needs context. A playful line only works when it supports the brand and helps the user recover.
